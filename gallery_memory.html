閉じ込められた想い

MEMORIES WITHIN

硝子の中に。
光の中に。
季節の中に。

いつか見た景色や、忘れたくない一瞬を、
小さな世界の中に閉じ込めました。
泡沫に閉じ込めた夢
消えてしまうからこそ美しい。 儚い夢を、ひとつの泡の中に閉じ込めた作品です。
MEMORY 01
空に放した金魚
水の中だけが世界じゃない。 想いはいつか、空さえ自由に泳いでゆきます。
MEMORY 02
星空をひとくち
夏祭りの夜に見上げた星空。 甘い記憶とともに、小さな硝子の中へ閉じ込めました。
MEMORY 03
硝子の中のふたり
近くにいるのに、触れられない。 硝子の向こうで交わる、ふたつの静かな想いを描きました。
MEMORY 04
あの日の夏を描いて
過ぎ去った夏は戻らない。 だからこそ、あの日の景色をキャンバスの中に残しました。
MEMORY 05
掌の中の未来
まだ誰も知らない未来の街。 小さな世界の中に、無限に広がる可能性を描きました。
MEMORY 06
掬いきれない夏
水面に揺れる、あの夏の記憶。 掬おうとするほど、指の間から静かにこぼれてゆきます。
MEMORY 07
傘の中の夜空
雨の日だけ開く、私だけの夜空。 傘の中に広がる、小さな宇宙を描いた作品です。
MEMORY 08
色彩の記憶
時が過ぎても、色だけは鮮やかに残る。 忘れたくない記憶の色を、一枚の世界に閉じ込めました。
