CHARACTER 01
白銀の騎士
大きなスライムと旅をする白銀の騎士。幻想世界の冒険を、少しだけ優しく描いたひととき。
CHARACTER 02
瞳に抱かれて
無数の瞳に囲まれながら、ひとつの瞳を静かに抱く少女。見つめる者と、見つめられる者の境界。
CHARACTER 03
星を掌に
掌に浮かぶ小さな惑星。遠い宇宙の光を見つめる、星界の住人。
CHARACTER 04
白狐の花嫁
白銀の髪と紅白の花に包まれた妖狐。月夜の社で静かにこちらを見つめる。
CHARACTER 05
紫電の騎士
紅と紫の雷光を纏い、剣を振るうエルフの騎士。静かな美しさと激しい力が交差する瞬間。
CHARACTER 06
向日葵のエルフ
真夏の陽射しと一面の向日葵。幻想世界にも、こんな何気ない夏の日がある。
CHARACTER 07
星涼み
青い花を纏った浴衣姿の少女。風鈴の音と星明かりに包まれる、静かな夏の夜。
CHARACTER 08
紫蝶
紫の蝶と宝石に覆われた少女。光と影の狭間で、蝶たちは静かに羽を広げる。
CHARACTER 09
蒼薔薇の姫
無数の青い薔薇と宝石に包まれた少女。青だけで紡がれた、透明な幻想。
CHARACTER 10
蒼炎の薔薇
青い炎を宿した一輪の薔薇。その光に触れるように、少女は静かに顔を寄せる。
